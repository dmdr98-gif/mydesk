# 서버 없이 Windows PC와 Android 연결 확인

자체 ID/릴레이 서버 없이 같은 LAN에서 직접 IP로 연결하는 확인표다. 외부망 ID
접속, Google 로그인, 계정 기기 목록은 별도 서버가 필요하므로 여기서 평가하지 않는다.
기본 직접 IP 접속은 꺼져 있으며 Windows 쪽에서 직접 켜야 한다.

## 준비할 것

- Windows 10/11 x64 PC와 S23 Ultra를 서로 통신 가능한 같은 Wi-Fi/LAN에 연결한다.
- Windows EXE 또는 MSI와 Android arm64 APK를 준비한다. 현재 `artifacts/` 파일은
  2026-11-16 빌드이며 이후 소스 변경이 들어 있는 새 빌드는 아니다.
- Windows MSI 설치·서비스·방화벽 변경에는 관리자 승인이 필요할 수 있다.
- Android 테스트 APK는 CI 디버그 키 서명이다. 다른 키로 서명된 기존 설치본과
  덮어쓰기 설치가 안 될 수 있다. 삭제 시 설정도 지워지므로 먼저 설치 버전을 기록한다.

## 첫 연결

1. Windows에서 everywhere를 실행한다. MSI를 썼다면 서비스가 실행 중인지 확인한다.
2. **설정 → 보안 → 직접 IP 액세스 허용**을 켠다. TCP 기본 포트는 21118이다.
3. Windows의 `ipconfig`에서 같은 LAN 어댑터의 IPv4 주소를 확인한다.
4. Windows 방화벽에서 해당 개인 네트워크의 everywhere 수신을 허용한다.
   게스트 Wi-Fi/기기 격리 네트워크는 피한다.
5. Android에서 상대 ID 칸에 `192.168.1.20:21118`처럼 실제 Windows IP를 입력한다.
6. Windows에서 연결 요청을 승인하거나 Windows에 표시·설정된 접속 비밀번호로
   인증한다. 서버 상태가 **서버 미설정**이어도 직접 IP 접속에는 지장이 없다.

접속이 안 될 때 Windows PowerShell에서 아래 읽기 전용 명령으로 리스너를 확인한다.
표시가 없으면 서비스/직접 IP 옵션/포트를 먼저 확인한다. 표시가 있어도 방화벽과
Wi-Fi 격리는 별도 확인해야 한다.

```powershell
Get-NetTCPConnection -State Listen -LocalPort 21118 -ErrorAction SilentlyContinue
Get-Service -Name everywhere -ErrorAction SilentlyContinue
```

## 실기 결과 기록

현재 아래 항목은 코드 존재만 확인되었으며 실기 통과로 기록하지 않았다.

| 확인 | 기대 결과 | 결과/증상 |
| --- | --- | --- |
| 화면·입력 | 화면 표시, 터치/마우스/키보드 및 한글 입력 가능 | 미확인 |
| 소리 | Windows 소리가 Android에서 재생됨 | 미확인 |
| 텍스트 클립보드 | 양방향 텍스트 복사 가능. Android OS의 클립보드 제약도 기록 | 미확인 |
| 파일 전송 | 폰→PC, PC→폰 파일이 정상 열리고 크기가 일치 | 미확인 |
| 재접속 | 세션 종료·Wi-Fi 재연결 후 다시 인증/접속 가능 | 미확인 |
| 권한 | Windows에서 입력/파일/터미널 권한을 끄면 해당 작업 거부 | 미확인 |
| 설치형 동작 | MSI 설치·제거·재부팅 후 서비스/트레이/설정 경로 정상 | 미확인 |
| 브랜딩·도움말 | everywhere 표기, 도움말·소스·라이선스 링크 정상 | 미확인 |

결과에는 앱 버전과 빌드, Windows 버전, GPU, Android 버전, 접속 IP/포트,
성공/실패 항목과 재현 순서를 함께 남긴다. 비밀번호·개인키는 기록하지 않는다.
직접 접속이 끝나면 해당 옵션을 끌지 결정한다.

## Steven님 준비가 필요한 후속 항목

외부망 ID 접속을 하려면 공인 주소가 있는 VPS 등의 hbbs/hbbr 서버와 공개키가
필요하다. 박스 중계 실험은 운영에 부적합 판정을 받았으므로 이번 확인에 사용하지
않는다. 정식 배포에는 Windows 서명 수단과 고정 Android 서명키, 제품 정책·배포
도메인 확정이 필요하다. 비밀키를 저장소나 채팅에 올리지 않는다.
